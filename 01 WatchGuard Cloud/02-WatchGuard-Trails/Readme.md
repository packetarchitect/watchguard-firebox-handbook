## What Are WatchGuard Trials?

WatchGuard trials let you evaluate additional WatchGuard security features and products before purchasing or fully deploying them.

- Trials generally start at **30 days**.
- Many trials can be extended.
- Trial availability and activation location depend on the product.
- Some trials are started through **Managed Products** in the WatchGuard portal.
- Other trials are started from **WatchGuard Cloud**.

> **Key point:** Do not assume every WatchGuard trial is activated in WatchGuard Cloud.

| Product area | Trial examples mentioned |
|---|---|
| Firebox security | **Total Security Suite** |
| Identity security | **AuthPoint** |
| Endpoint security | Advanced EPDR and endpoint modules |
| Other cloud products | FireCloud, ThreatSync+ Email Protection, Systems Management, DNSWatchGO |

### Firebox Total Security Suite Trial

If a Firebox is protecting the network, you can trial **Total Security Suite** to evaluate the Firebox’s available security protections.

Specifically mentions features such as:

- **ThreatSync**
- **APT Blocker**

## Where to Activate Trials

### Managed Product Trials

To activate some trials from the WatchGuard portal:

```text
watchguard.com
→ Sign in
→ Support Center
→ My WatchGuard
→ Managed Products
```

For a Firebox Total Security Suite trial:

```text
Managed Products
→ Network Security
→ Select Firebox with a support license
→ Activate Total Security Suite trial
```

After activation, the newly enabled features become available on the Firebox.

The video states that an extension can be requested by repeating the activation process one additional time.

### Endpoint-Related Trials

From **Managed Products**, select **Endpoint Security** to find trials for products mentioned in the video, including:

- DNSWatchGO
- Systems Management
- Email Protection

### WatchGuard Cloud Trials

For cloud-solution trials:

```text
cloud.watchguard.com
→ Administration
→ Trials
```

The cloud trials lists:

- AuthPoint
- Endpoint Security
- FireCloud
- ThreatSync+ Email Protection

To start a trial, enable the required product trial with its slider. Once active, begin configuration and use of the product.

To upgrade or extend an active trial:

```text
Trials
→ Three-dot menu
→ Upgrade or Extend
```

## Service Provider Trial Management

If you use a **Service Provider** account in WatchGuard Cloud, the same **Trials** page can be used to manage trials across Subscriber accounts.

This matches the earlier Partner versus End User model:

```text
Tier-1 Service Provider
        ↓
Manages trials for Subscriber accounts
```

## Recommended Trial Workflow

```text
Identify product to evaluate
        ↓
Determine activation location
(Managed Products or WatchGuard Cloud)
        ↓
Activate the trial
        ↓
Configure the product or feature
        ↓
Verify that it is enabled and working
        ↓
Use Help Center and Learning Center resources
        ↓
Decide whether to extend, upgrade, or stop using it
```

## Key Takeaways

- Most WatchGuard trials start at 30 days.
- Many trials can be extended, but the video does not state that every product supports extension.
- Firebox Total Security Suite is activated through **Managed Products** for an eligible Firebox.
- AuthPoint and other cloud solutions can be started from **WatchGuard Cloud → Administration → Trials**.
- Service Providers can manage trials for their Subscriber accounts.
- Use the WatchGuard Help Center and Learning Center to continue learning after activation.
